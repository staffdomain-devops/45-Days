<objective>
Implement two scripts that complete the pre-generation pipeline:

1. **`compute_campaign_tokens.py`** — calculates runtime tokens for the campaign (current date, EOFY timing context, days to EOFY). Writes `$RUNNER_TEMP/campaign_tokens.json` (TOK-01, TOK-02).

Purpose: Both scripts are small but critical pipeline steps. They have no external API dependencies in Phase 1 — meaning the workflow can run end-to-end even before Chorus credentials are ever validated. This keeps Phase 1 free of dependencies on Phase 2 work.

Output: Two Python scripts that each produce a JSON file in `$RUNNER_TEMP`.

    2. **Imports**: `os`, `json`, `logging`, `datetime`, `timezone`, `date` (from `datetime`).

    3. **Logging setup**: same pattern as fetch_hubspot.py — `logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")`; `log = logging.getLogger("compute_campaign_tokens")`.

    4. **Function `compute_eofy_context(today: date) -> tuple[str, int]`** — returns `(timing_context_label, days_to_eofy)`. EOFY in Australia is 30 June. Compute the next 30 June from `today`:
       - If `today.month < 6 or (today.month == 6 and today.day <= 30)`: EOFY is `date(today.year, 6, 30)`
       - Else (July 1 onward): EOFY is `date(today.year + 1, 6, 30)`
       - `days_to_eofy = (eofy_date - today).days`
       - Label rules (per rebuild-prompt.md):
         - `days_to_eofy > 45`: `"pre_eofy_full"` (full 45-day cadence applicable)
         - `0 <= days_to_eofy <= 45`: `"pre_eofy_compressed"` (cadence must be compressed)
         - `days_to_eofy < 0`: `"post_eofy"` (theoretically unreachable since we recompute next EOFY, but include for safety)

    5. **`if __name__ == "__main__":`** block:
       ```python
       runner_temp = os.environ.get("RUNNER_TEMP", ".")
       today = datetime.now(timezone.utc).date()
       timing_context, days = compute_eofy_context(today)

       tokens = {
           "current_date": today.isoformat(),  # YYYY-MM-DD
           "eofy_timing_context": timing_context,
           "days_to_eofy": days,
       }

       out_path = os.path.join(runner_temp, "campaign_tokens.json")
       with open(out_path, "w", encoding="utf-8") as f:
           json.dump(tokens, f, indent=2)
       log.info(f"Wrote {out_path}: current_date={tokens['current_date']}, eofy_timing_context={timing_context}, days_to_eofy={days}")
       ```

    The output JSON top-level keys MUST be exactly `current_date`, `eofy_timing_context`, `days_to_eofy` — these match `{{campaign.current_date}}`, `{{campaign.eofy_timing_context}}`, `{{campaign.days_to_eofy}}` in `prompt_template.md` after the `campaign.` prefix is stripped during substitution.
