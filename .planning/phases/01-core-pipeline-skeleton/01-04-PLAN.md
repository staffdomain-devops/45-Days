<objective>
Implement the AI generation step. `generate_campaign.py`:
1. Reads all three input JSON files from `$RUNNER_TEMP` (AI-01)
2. Assembles a labelled `activity_history` string from emails + meetings + transcripts (AI-02)
3. Substitutes `{{token.name}}` placeholders in `prompt_template.md` from three namespaces (AI-03)
4. Calls `claude-sonnet-4-6` with `max_tokens=16384` and a system prompt enforcing AU English, no em/en dashes as separators, raw JSON only (AI-04)
5. Validates the response has all required keys and strips banned punctuation (AI-05)
6. Writes `campaign_output.json` to `$RUNNER_TEMP` (AI-06)

This is the heart of the pipeline. AI-07 (prompt_template.md with placeholders and schema) was satisfied in Plan 01; this script consumes that template.

Purpose: Without this script, there's no campaign content. Every input gathered by `fetch_hubspot.py` and `compute_campaign_tokens.py` feeds in here.
